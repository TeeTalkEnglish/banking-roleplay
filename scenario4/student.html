Real-Life Banking Vocabulary

  • Phishing — fake messages trying to steal information
  • Impersonation — pretending to be a trusted organisation
  • One-time code — temporary security code
  • Freeze — temporarily stop account activity
  • Dispute — ask for payment investigation
  • Callback — call the official number yourself
